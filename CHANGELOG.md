# Changelog

## v0.2.6 — 2026-11-14

First public release, based on the tested v0.2.6 build.

- Extra Networks quick view modes: Cards, No Preview and List, selected separately per category.
- Customizable name position and length, card spacing, aspect ratio, preview fitting and hover zoom.
- Fixed Cards per Row (2–6), preserving Forge card dimensions without stretched previews or collapsed rows.
- Retained native Extra Networks search, sorting and card actions across all modes.
- Retained original icon-size (10–32 px) and maximum-resolution (default/2048/4096/8192) controls.
- No new Python dependencies or Forge core modifications.
